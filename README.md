# SQL Learning

This repository is a personal learning workspace for SQL and T-SQL. It is focused on building practical skills through the courses:

- T-SQL Fundamentals
- SQL Bootcamp on Udemy

## Purpose

The goal of this repo is to store notes, examples, and SQL practice scripts while learning SQL and T-SQL concepts.

## What you'll find here

- SQL queries and examples
- Practice exercises
- Notes from learning materials
- Small examples for common SQL topics

## Topics covered

- Basic `SELECT` queries
- Filtering and sorting data
- Joins and subqueries
- Grouping and aggregation
- T-SQL basics and database concepts

## Goal

To improve SQL and T-SQL skills through hands-on practice and documentation.
